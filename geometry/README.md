# Geometry

Place the CAD source files for the steering knuckle here, for example:

- `steering_knuckle.stp` (STEP) or `steering_knuckle.x_t` (Parasolid) — neutral CAD exchange formats
- `steering_knuckle.scdoc` — ANSYS SpaceClaim document (after de-featuring)

Native CAD/solver files are typically large and are excluded from version control via `.gitignore`.
The de-featuring and clean-up steps performed on this geometry are described in
[`../report/CAE_Report_Steering_Knuckle.md`](../report/CAE_Report_Steering_Knuckle.md), Section 2.
